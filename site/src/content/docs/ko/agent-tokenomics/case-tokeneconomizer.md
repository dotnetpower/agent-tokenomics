[TokenEconomizer](https://github.com/microsoft/TokenEconomizer)는 코딩 에이전트(Claude Code, Codex, GitHub Copilot CLI, Pi, 실험적으로 opencode와 Cursor Agent)를 위한
경험 기반의 블랙박스 비용 제어 플러그인입니다. **같은 저장소**에서 에이전트가 진행한 이전 세션으로부터 학습하며,
에이전트의 모델이나 코드는 변경하지 않습니다. 이 페이지는 공개된 설계를 우리의 표현으로 요약합니다.

## 세 가지 메커니즘

| 메커니즘 | 하는 일 | 보고된 기본값 |
|----------|---------|---------------|
| **마이크로 스킬** | 반복되는 실패와, 최근 세션을 검토하는 모델로부터 저장소 사실(명령 철자, 환경 변수, 빌드 순서, 파일 위치)을 학습합니다. 확인된 사실은 세션 시작 시 한 번 알려 주고, 반박되면 삭제합니다 | 세션 *k* = 3개마다 검토, 세션 3개에 걸쳐 확인 |
| **도구 가지치기** | 프롬프트 *p*개 동안 세션 *m*개 이상에서, 또는 세션 *s*개 동안 사용되지 않은 도구 정의를 에이전트 자체 설정으로 제외합니다. 명령 하나로 복원할 수 있습니다 | *p* = 10, *m* = 2, *s* = 5 |
| **실패 루프 개입(루프 가드)** | 판정 모델이 막힌 턴을 점검합니다. 확신도가 *c* 이상이면 리디렉션을 한 번 주입하고, 그래도 막혀 있으면 사용자에게 중단하는 방법을 알립니다. 턴을 직접 중단하지는 않습니다 | *c* = 0.7, 턴당 리디렉션 *r* = 1회 |

## 보고된 결과

저자들은 여섯 개 저장소의 SWE-Bench 작업 277개와 에이전트–모델 조합 5개에서 평균 비용이
**18.4–30.9% 낮아졌다**고 보고합니다. 저장소 × 조합 30개 셀 모두에서 비용이 더 낮았고,
조합 5개 중 4개에서 Pass@1이 더 높았습니다. 비용에는 TokenEconomizer 자체가 수행하는 모든 모델 호출이 포함됩니다.
자세한 내용은 [논문](https://arxiv.org/abs/2610.22732)과 [프로젝트 페이지](https://tokeneconomizer.github.io)를 참고하세요.

## 이 가이드와의 대응

| TokenEconomizer | 낭비 범주([2단계](../02-isolate/)) | 수정([4단계](../04-improve/)) |
|-----------------|-------------------------------------|-------------------------------|
| 마이크로 스킬 | 저장소 사실 재학습 | 확인된 짧은 사실을 세션 시작 시 제공 |
| 도구 가지치기 | 사용하지 않는 도구 | 도구 정의 가지치기 |
| 루프 가드 | 실패 루프 | 리디렉션 한 번, 이후 사용자에게 알림 |

본받을 만한 설계 원칙은 다음과 같습니다. 에이전트의 **자체 설정**을 통해 동작합니다. 학습한 사실을 알려 주기 전에
**확인**을 요구합니다. 개입 횟수에 **상한**을 둡니다. **최적화 도구 자체의 비용**을 집계에 포함합니다.
**실패 시 개방**(fail open)을 택합니다. 최적화 도구가 실패하면 세션은 설치되지 않은 것처럼 계속 진행됩니다.

## 추가 자료(논문)

학회 등급 순, 같은 등급 안에서는 인용 수 순으로 정렬했습니다. 각 결과는 자신의 워크로드에서 검증해야 할 가설로 취급합니다. 전체 목록은 [논문](../../papers/)을 참고하세요.

- [SWE-agent: Agent-Computer Interfaces Enable Automated Software Engineering](https://arxiv.org/abs/2405.15793) — NeurIPS 2024, 인용 2,357회. 간결하고 제한된 관찰을 포함한 인터페이스 설계가 에이전트의 성공률을 좌우함을 보여 줍니다.
- [Agent Workflow Memory](https://arxiv.org/abs/2409.07429) — ICML 2024, 인용 451회. 에이전트가 과거 궤적에서 재사용 가능한 워크플로를 유도해 다시 활용합니다. 취지가 마이크로 스킬과 비슷합니다.
- [RAG-MCP: Mitigating Prompt Bloat in LLM Tool Selection via Retrieval-Augmented Generation](https://arxiv.org/abs/2505.03275) — 프리프린트 2025, 인용 41회. 모든 도구를 로드하는 대신 관련 있는 MCP 도구 설명만 검색해 가져와 프롬프트 비대화를 줄입니다.
- [Evaluating AGENTS.md: Are Repository-Level Context Files Helpful for Coding Agents?](https://arxiv.org/abs/2602.11988) — 프리프린트 2026, 인용 36회. 저장소 수준 컨텍스트 파일은 대체로 작업 성공률을 높이지 못했고 추론 비용은 평균 20% 넘게 늘렸습니다.
- [TokenEconomizer: Experience-Driven Black-Box Cost Control for Coding Agents](https://arxiv.org/abs/2610.22732) — 프리프린트 2026, 인용 0회. 마이크로 스킬, 도구 가지치기, 루프 가드가 이전 세션의 경험을 활용해 코딩 에이전트의 비용을 줄입니다.
