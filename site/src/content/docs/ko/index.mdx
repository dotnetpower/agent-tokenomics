## 원칙

1. **먼저 측정합니다.** 내 세션에서 얻은 수치 없이는 최적화하지 않습니다.
2. **품질은 안전장치입니다.** 작업 성공률이 유지될 때만 토큰 절감을 인정합니다.
3. **한 번에 하나만 바꿉니다.** 그래야 무엇이 효과가 있었는지 알 수 있습니다.
4. **출처를 밝히거나 직접 측정합니다.** 모든 정량적 주장은 출처 또는 재현 가능한 로그에 연결합니다.

이 프로젝트는 [microsoft/TokenEconomizer](https://github.com/microsoft/TokenEconomizer)에서 영감을 얻었습니다.
TokenEconomizer는 마이크로 스킬, 도구 가지치기, 실패 루프 개입으로 코딩 에이전트의 비용을 줄입니다.
[사례 연구](agent-tokenomics/case-tokeneconomizer/), 엄선한 [리소스](resources/)(도구와 리포지토리),
[논문 순위](papers/)도 함께 확인해 보세요.
