## Principles

1. **Measure first.** No optimization without a number from your own sessions.
2. **Quality is a guardrail.** Fewer tokens only count if task success holds.
3. **One change at a time.** Otherwise you cannot tell what worked.
4. **Cite or measure.** Every quantitative claim links to a source or a reproducible log.

This project is inspired by [microsoft/TokenEconomizer](https://github.com/microsoft/TokenEconomizer),
which cuts coding-agent cost using micro-skills, tool pruning, and failure-loop intervention.
See the [case study](agent-tokenomics/case-tokeneconomizer/) the curated [resources](resources/)
(tools and repositories), and [ranked papers](papers/).
